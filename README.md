## The entry

One line, 1 to 240 characters: a quiet, earned moment of pride — a night baker whose twelfth loaf finally sings after eleven failed batches.

## How it works

`main.py` (pure stdlib Python 3.13, no third-party imports) writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), asserting first that the text is a single line inside the 1–240 character gate, then reading the file back to verify it matches the intended text exactly.

## Run

```sh
python3 main.py
```
